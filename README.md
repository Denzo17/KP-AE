# KP-AE — формирование счетов (КП)

Отдельный сайт: менеджер заполняет форму, получает счёт по постоянной ссылке
и PDF. Внешних интеграций нет — данные вводятся вручную.

## Что умеет

- Две компании-поставщика (ООО «А-Э» и ИП Лутонина Е. С.) с реквизитами из
  образцов счетов. Выбор компании сам задаёт коэффициент, ставку НДС и то,
  входит ли логистика в цену.
- Расчёт конечной цены, живой пересчёт прямо в форме.
- Номенклатура «с памятью»: введённые позиции запоминаются и подставляются
  в следующий раз. Есть импорт CSV.
- Сохранение, список и редактирование уже сформированных счетов. Ссылка
  после правок не меняется и показывает свежую версию.
- PDF с именем файла по клиенту: `Счёт 128 ООО «Ромашка».pdf`.

## Логика расчёта

Цена за единицу считается так:

```
((цена закупа в валюте × курс + доставка + страховка) × коэф. компании) × наценка
```

| | ООО «А-Э» | ИП Лутонина Е. С. |
|---|---|---|
| Коэффициент | 1,5 | 1,2 |
| НДС | 22% | 5% |
| Доставка и страховка в цене | нет | да |

Ставка НДС подставляется автоматически по выбору компании, но её можно
переопределить вручную (22 / 5 / 0).

**НДС считается «в том числе»** — как в присланных образцах счетов: он
выделяется из итоговой суммы, а не начисляется сверху.

Минимальная наценка задана условиями оплаты. Указать больше можно, меньше —
нельзя, форма не даст сохранить счёт:

| Условия оплаты | Минимальная наценка |
|---|---|
| Отсрочка платежа 100% | 1,35 |
| 50% предоплата / 50% перед отгрузкой | 1,25 |
| 100% предоплата | 1,2 |
| Свой вариант | не задана |

Наценка применяется либо ко всем позициям сразу, либо индивидуально по каждой.

## Структура

```
config.js          всё, что меняется при переезде (адрес, порт, пути, вебхуки)
src/companies.js   реквизиты и налоговые правила поставщиков
src/model.js       справочники, нормализация, расчёт, проверки — здесь живут критерии
src/render.js      печатная форма: одна для веб-страницы и для PDF
src/pdf.js         печать через headless chromium
src/storage.js     хранение счетов (файлы JSON)
src/catalog.js     номенклатура с памятью и пользовательские валюты
src/bitrix.js      точка интеграции с Битрикс24 (пока заглушка)
src/server.js      маршруты
public/            форма ввода
```

Новые критерии добавляются в `src/model.js`: жёсткие правила — в `validate()`,
влияющие на цену — в `calculate()`. Сервер и шаблон при этом не трогаются.

## Запуск

```bash
npm install
BASE_URL=https://schet.example.ru CHROMIUM_PATH=/usr/bin/chromium npm start
```

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `PORT` | порт (по умолчанию 3000) |
| `BASE_URL` | внешний адрес сайта — подставляется в ссылки на счета |
| `DATA_DIR` | каталог хранения (по умолчанию `./data`) |
| `CHROMIUM_PATH` | системный chromium для печати PDF |
| `BITRIX_ENABLED`, `BITRIX_WEBHOOK_URL` | будущая интеграция с Битрикс24 |

## Деплой на Beget VPS

```bash
apt install -y nodejs npm chromium
git clone <репозиторий> /opt/kp-ae && cd /opt/kp-ae
PUPPETEER_SKIP_DOWNLOAD=true npm install --omit=dev
```

Дальше — systemd-юнит с переменными окружения выше и nginx впереди с
Let's Encrypt. Chromium ставится системный, поэтому `PUPPETEER_SKIP_DOWNLOAD`
экономит ~150 МБ на каждом деплое.

`DATA_DIR` лучше вынести за пределы каталога с кодом (например,
`/var/lib/kp-ae`), чтобы деплой не затирал сохранённые счета.

## Переезд на другой сервер или аккаунт

1. Скопировать каталог `DATA_DIR` — в нём все счета и справочник номенклатуры.
2. Поменять `BASE_URL` на новый домен. Больше адресов нигде в коде нет.
3. Перевыпустить SSL, проверить, что chromium на месте (`CHROMIUM_PATH`).

Реквизиты компаний лежат в `src/companies.js` — при смене владельца правится
только этот файл.

## Открытые вопросы

- **Доставка и страховка** сейчас вводятся в рублях за единицу товара и
  участвуют в расчёте только у ИП. Если по факту это сумма на всю поставку —
  правится в `calculate()`.
- **Текущая номенклатура** пока не загружена: нужен выгруженный файл. Импорт
  CSV готов, колонки — «Наименование», «Артикул», «Ед.», «Цена закупа», «Вес».
- **Битрикс24**: заложена только точка входа, реального подключения нет.
