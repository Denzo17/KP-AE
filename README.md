# KP-AE — формирование счетов (КП)

Отдельный сайт: менеджер заполняет форму, получает счёт по постоянной ссылке
и PDF. Внешних интеграций нет — данные вводятся вручную.

## Что умеет

- Две компании-поставщика (ООО «А-Э» и ИП Лутонина Е. С.) с реквизитами из
  образцов счетов. Выбор компании сам задаёт коэффициент, ставку НДС и то,
  входит ли логистика в цену.
- Расчёт конечной цены, живой пересчёт прямо в форме.
- Номенклатура «с памятью»: введённые позиции запоминаются и подставляются
  в следующий раз. Есть импорт CSV.
- Сохранение, список и редактирование уже сформированных счетов. Ссылка
  после правок не меняется и показывает свежую версию.
- PDF с именем файла по клиенту: `Счёт 128 ООО «Ромашка».pdf`.
- Автонумерация: номер подставляется сам, сквозной в пределах компании и года,
  но остаётся редактируемым — вписанный руками автоподстановка не трогает.
- Сумма прописью в печатной форме, со всеми склонениями
  («Одна тысяча», «Две тысячи», «01 копейка»).

## Доступ

Форма и API закрыты паролем (HTTP Basic). **Страница счёта и PDF остаются
открытыми по ссылке** — её отправляют клиенту, и он ничего не вводит; защита
ссылки в неподбираемом идентификаторе.

Без `AUTH_PASSWORD` сервис не стартует: иначе на публичном домене список всех
счетов с клиентами и суммами доступен любому. Для локальной разработки —
`AUTH_DISABLED=1`.

## Логика расчёта

Цена за единицу считается так:

```
((цена закупа в валюте × курс + доставка + страховка) × коэф. компании) × наценка
```

| | ООО «А-Э» | ИП Лутонина Е. С. |
|---|---|---|
| Коэффициент | 1,5 | 1,2 |
| НДС | 22% | 5% |
| Доставка и страховка в цене | нет | да |

Ставка НДС подставляется автоматически по выбору компании, но её можно
переопределить вручную (22 / 5 / 0).

**НДС считается «в том числе»** — как в присланных образцах счетов: он
выделяется из итоговой суммы, а не начисляется сверху.

Минимальная наценка задана условиями оплаты. Указать больше можно, меньше —
нельзя, форма не даст сохранить счёт:

| Условия оплаты | Минимальная наценка |
|---|---|
| Отсрочка платежа 100% | 1,35 |
| 50% предоплата / 50% перед отгрузкой | 1,25 |
| 100% предоплата | 1,2 |
| Свой вариант | не задана |

Наценка применяется либо ко всем позициям сразу, либо индивидуально по каждой.

## Структура

```
config.js          всё, что меняется при переезде (адрес, порт, пути, вебхуки)
src/companies.js   реквизиты и налоговые правила поставщиков
src/model.js       справочники, нормализация, расчёт, проверки — здесь живут критерии
src/render.js      печатная форма: одна для веб-страницы и для PDF
src/amount-in-words.js  сумма прописью
src/numbering.js   автонумерация счетов
src/pdf.js         печать через headless chromium
src/storage.js     хранение счетов (файлы JSON)
src/catalog.js     номенклатура с памятью и пользовательские валюты
src/bitrix.js      точка интеграции с Битрикс24 (пока заглушка)
src/server.js      маршруты
public/            форма ввода
```

Новые критерии добавляются в `src/model.js`: жёсткие правила — в `validate()`,
влияющие на цену — в `calculate()`. Сервер и шаблон при этом не трогаются.

## Запуск

```bash
npm install
BASE_URL=https://schet.example.ru CHROMIUM_PATH=/usr/bin/chromium npm start
```

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `PORT` | порт (по умолчанию 3000) |
| `BASE_URL` | внешний адрес сайта — подставляется в ссылки на счета |
| `DATA_DIR` | каталог хранения (по умолчанию `./data`) |
| `CHROMIUM_PATH` | системный chromium для печати PDF |
| `BITRIX_ENABLED`, `BITRIX_WEBHOOK_URL` | будущая интеграция с Битрикс24 |

## Деплой на Beget VPS

Минимум по железу: **2 ГБ RAM** и 10 ГБ диска. Печать держит chromium в
памяти (~300 МБ вместе с вспомогательными процессами), одновременных печатей
не больше двух — остальные ждут очереди, чтобы поток запросов не съел память.

### 1. Пакеты

```bash
# Node 20 LTS — в стандартных репозиториях версия обычно старее, чем нужно
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs nginx chromium

# ОБЯЗАТЕЛЬНО: без этих шрифтов кириллица и знак ₽ в PDF превратятся в квадраты
sudo apt install -y fonts-liberation fonts-dejavu-core
```

Печатная форма набрана Times New Roman, chromium подставляет вместо него
Liberation Serif, а символ рубля берёт из DejaVu Sans — оба пакета нужны.
Проверить, что подстановка работает: `fc-match "Times New Roman"`.

Имя пакета с chromium на некоторых сборках — `chromium-browser`. Путь до
бинарника (`which chromium`) идёт в `CHROMIUM_PATH`.

### 2. Пользователь, код, данные

```bash
sudo useradd -r -s /usr/sbin/nologin kpae
sudo git clone https://github.com/Denzo17/KP-AE.git /opt/kp-ae
cd /opt/kp-ae
sudo PUPPETEER_SKIP_DOWNLOAD=true npm ci --omit=dev

sudo mkdir -p /var/lib/kp-ae
sudo chown -R kpae:kpae /var/lib/kp-ae
```

`PUPPETEER_SKIP_DOWNLOAD` экономит ~150 МБ на каждом деплое: chromium берётся
системный.

### 3. Настройки

```bash
sudo cp .env.example /etc/kp-ae.env
sudo nano /etc/kp-ae.env          # домен в BASE_URL и обязательно AUTH_PASSWORD
sudo chmod 600 /etc/kp-ae.env
sudo chown kpae:kpae /etc/kp-ae.env
```

### 4. Сервис и nginx

```bash
sudo cp deploy/kp-ae.service /etc/systemd/system/
sudo systemctl enable --now kp-ae
sudo systemctl status kp-ae

sudo cp deploy/nginx.conf /etc/nginx/sites-available/kp-ae
sudo nano /etc/nginx/sites-available/kp-ae     # подставить свой домен
sudo ln -s /etc/nginx/sites-available/kp-ae /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d schet.example.ru
```

### 5. Проверка

```bash
curl -fsS https://schet.example.ru/healthz        # {"ok":true}
curl -o /dev/null -w '%{http_code}\n' https://schet.example.ru/   # 401 без пароля
journalctl -u kp-ae -f
```

Если в логе есть «chromium недоступен» — проверить `CHROMIUM_PATH`. Страницы
счетов при этом работают, не печатается только PDF.

### Обновление

```bash
sudo -u kpae deploy/update.sh
```

Скрипт подтягивает код, ставит зависимости, прогоняет тесты и перезапускает
сервис с проверкой живости.

## Переезд на другой сервер или аккаунт

1. Скопировать каталог `DATA_DIR` — в нём все счета и справочник номенклатуры.
2. Поменять `BASE_URL` на новый домен. Больше адресов нигде в коде нет.
3. Перевыпустить SSL, проверить, что chromium на месте (`CHROMIUM_PATH`).

Реквизиты компаний лежат в `src/companies.js` — при смене владельца правится
только этот файл.

## Открытые вопросы

- **Доставка и страховка** сейчас вводятся в рублях за единицу товара и
  участвуют в расчёте только у ИП. Если по факту это сумма на всю поставку —
  правится в `calculate()`.
- **Текущая номенклатура** пока не загружена: нужен выгруженный файл. Импорт
  CSV готов, колонки — «Наименование», «Артикул», «Ед.», «Цена закупа», «Вес».
- **Битрикс24**: заложена только точка входа, реального подключения нет.
